# Analysis scripts

R scripts for the TE tissue-enrichment and recurrence analysis will be stored here.

Run scripts from the repository root unless a script explicitly says otherwise. The expected input directory is `data/32files/`; generated tables should be written to `outputs/`.

The primary all-significant-TE script is being prepared from the working analysis script. Its input checks, output paths, package requirements, and naming harmonisation should be reviewed before the repository is treated as a final reproducibility release.
