# Expected input files

Place the 32 approved tissue-level result files named `TEresSig*.csv` in this directory. Each file should include the columns `TE`, `baseMean`, `log2FoldChange`, `lfcSE`, `stat`, `pvalue`, and `padj`.

The script derives each tissue label from the filename. These data files are not included here yet; confirm their provenance and redistribution permissions before adding them.
